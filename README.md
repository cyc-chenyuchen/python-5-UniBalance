# python-5-UniBalance

## 五年校園經營

首頁只有一個校園問題輸入欄。送出後先選擇依問題產生的校務策略，再經營 5 年、每年 2 學期，共 10 個學期。每局會隨機取得不同校園背景，影響開局財政、人口、資源與教職員生狀態。每局也會追蹤一位教職員生的三幕個人主線，連續三個學期的抉擇會改變合作程度與故事結局。每學期需回應教職員生問題，並選擇建設、政策、財政或資源措施；危機有止損門檻、機會可爭取基金紅利、協商會影響角色信任、投票會改變群體滿意度，人物故事則推進主線。每個決策除了即時效果，也會留下延遲影響，並在後續學期結算；最後一學期會一併結算尚未到期的後果。每回合會依校園事件及發展措施，產生一則可重現的匿名版反應和原創諧音梗；每年另有一項隨機挑戰，完成可獲得基金獎勵。八位教職員生各有獨立立繪、性格與個人目標；遊玩可解鎖不同稱號，並在排行榜比較五年成果。

設定 `GEMINI_API_KEY` 與 `GEMINI_MODEL` 並關閉 `DEMO_MODE` 後，方案與校園事件由 Gemini API 依玩家問題、校務狀態、人物主線及歷次決策動態產生，並為選項提供延遲效果；事件以每批 2 個生成，避免每學期都呼叫 API。`DEMO_MODE=1` 時使用同樣支援多種事件、人物主線與延遲效果的離線示範內容，不會呼叫 Gemini。
