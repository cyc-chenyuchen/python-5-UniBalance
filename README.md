# python-5-UniBalance

## 五年校園經營

首頁只有一個校園問題輸入欄。送出後先選擇依問題產生的校務策略，再經營 5 年、每年 2 學期，共 10 個學期。每學期需回應一位教職員生的問題，並選擇建設、政策、財政或資源措施；選擇會影響校務基金、校園指標、人口與教職員生滿意度，也會牽動後續事件。每年另有一項隨機挑戰，完成可獲得基金獎勵。八位教職員生各有獨立立繪、性格與個人目標；玩家的選擇會持續改變個人信任與壓力，並影響 AI 後續生成的角色故事。遊玩可解鎖不同稱號，並在排行榜比較五年成果。

設定 `GEMINI_API_KEY` 與 `GEMINI_MODEL` 並關閉 `DEMO_MODE` 後，方案與校園事件由 Gemini API 依玩家問題、校務狀態及歷次決策動態產生；事件以每批 2 個生成，避免每學期都呼叫 API。`DEMO_MODE=1` 時使用離線示範內容，不會呼叫 Gemini。
