# python-5-UniBalance

## 十年校園經營

首頁只有一個校園問題輸入欄。送出後先選擇依問題產生的校務策略，再經營 10 年、每年 2 學期，共 20 個學期。每學期需回應一位教職員生的問題，並選擇建設、政策、財政或資源措施；選擇會影響校務基金、校園指標、人口與教職員生滿意度，也會牽動後續事件。完成 20 個學期後，可檢視十年決策年表、年度人口與評分，以及下一年度預測。

設定 `GEMINI_API_KEY` 與 `GEMINI_MODEL` 並關閉 `DEMO_MODE` 後，方案與校園事件由 Gemini API 依玩家問題、校務狀態及歷次決策動態產生；事件以每批 2 個生成，避免每學期都呼叫 API。`DEMO_MODE=1` 時使用離線示範內容，不會呼叫 Gemini。

執行測試：

```powershell
python -m unittest tests
```
